## 🌟 Overview

**Veccna AI** is a state-of-the-art multimodal AI platform modeled after Google Gemini. It features an ultra-responsive conversational workspace, deep thinking reasoning accordions, a 2,000,000-token context window, multimodal upload tools, and an ergonomic dark slate design tuned specifically to prevent eye fatigue.

## 🎨 Ergonomic Dark Slate Theme (Zero Pure Black)
To protect users and developers from eye strain during long sessions:
- **Primary Background:** `#09090B` (zinc-950 near-black)
- **Deep Slate Canvas:** `#0F172A` (slate-900)
- **Surfaces & Input Capsule:** `#131C2E` / `#131D31` / `#1E293B`
- **Gemini-Style Gradients:** Cyan (`#06B6D4`), Sky (`#38BDF8`), Indigo (`#818CF8`), Pink (`#F472B6`)
- **Strictly avoiding pure black (`#000000`)** to prevent stark contrast, glare, and ocular fatigue.

## ⚡ Platform Features (Just Like Gemini)

1. **Gemini-Style Collapsible Sidebar:**
   - Hamburger toggle, **"New chat"** pill button with icon.
   - Categorized **Recent Chats** with active conversation selection.
   - Quick links to **Model Architecture** and **Training Heritage** modals.

2. **Model Selector Dropdown:**
   - **Veccna 2.5 Pro (Thinking):** Best for complex reasoning, math, and code.
   - **Veccna 2.5 Flash:** Fast and versatile for everyday multimodal tasks.
   - **Veccna Deep Research:** Multi-step autonomous research and report synthesis.

3. **Welcome Hero & Suggestion Cards:**
   - Radiant 4-pointed Gemini-style animated star logo.
   - Personalized greeting: *"Hello, Amay — How can Veccna help you today?"*.
   - 4 Interactive suggestion cards that populate and execute prompts with 1 click.

4. **Conversational Stream & Deep Thinking:**
   - Real-time token streaming with syntax-highlighted code blocks and 1-click **Copy Code** button.
   - **"Thinking Process"** collapsible accordion displaying step-by-step reasoning.
   - Message action tools: Copy, Thumbs Up/Down, Share.

5. **Floating Bottom Input Dock:**
   - Pill capsule prompt container with auto-expanding textarea.
   - File & Image Upload button with interactive tag preview.
   - **Deep Think** & **Search** web-grounding toggle buttons.
   - Voice input trigger and dynamic send button.

6. **Model Architecture & Provenance Modal:**
   - Displays the 17.4B-parameter Synapse-X model card and training attribution to **Amay, Anshuman, Ankit & Aaryan**.
